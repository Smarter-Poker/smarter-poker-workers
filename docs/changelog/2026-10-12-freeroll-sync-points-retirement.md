# Freeroll sync no longer qualifies players with points

Owner direction on 2026-10-12 removes every points benefit outside leaderboards. The current freeroll-qualification-sync worker still derived tournament finish points and granted freeroll eligibility. This was a separate writer from the Commander UI/API. The ordinary scan included tournament_points, and a targeted freeroll_id request could invoke it independently.

The worker now scans cash_hours only and returns a points_rewards_retired skip for targeted legacy point configurations before reading tournament results or qualifications. The isolated position-points calculator and tournament-entry reader are removed. Cash-hours eligibility and existing manual overrides remain. Cash-hours upserts omit points_earned, retaining historical column values instead of resetting them. No schedules, leaderboard scoring, database schema, historical rows or financial balances change.
